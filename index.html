  1. 取得 Token(建議)：到 FinMind 官網(finmind.github.io)註冊並驗證信箱，登入後在使用者資訊頁複製 API token。有 Token 每小時可呼叫 600 次，沒有則 300 次。
  2. 開啟本頁：用瀏覽器開啟這個 HTML 檔即可，或放到 GitHub Pages。若瀏覽器主控台出現 CORS 錯誤，請改放 GitHub Pages 使用。
  3. 貼上 Token：切到「篩選」頁籤，貼到最上方的 Token 欄位。它只存在你的瀏覽器，不會上傳到別處。
  4. 逐一加入股票：在輸入欄輸入 4 碼代號或名稱(如 2330 或 台積電)，按 Enter 或「加入」。重複步驟加入所有要看的股票，不想要的按標籤上的 × 移除。清單會自動保存。
  5. 設定嚴格度：「基本面可未通過 N 項」預設 0，條件很嚴格，通過者會很少；可先改成 1 或 2。勾「不淘汰，全部評分」可看到每一檔的分數。
  6. 開始篩選：按「開始篩選」並等待進度條跑完，每檔約需數秒。若顯示額度用盡，等一小時後再按一次，已處理的股票會從快取接續。
  7. 看結果：點表頭排序，點任一列展開詳細資料：基本面各項是否通過、訊號與警示、PE、法人買賣超、五線譜價位。總分 75 以上為「強烈關注」，60 以上「關注」，45 以上「觀察」。
  8. 每天追蹤：每次篩選完成會自動存當日快照(同日重跑會覆蓋)。隔天再篩選一次，切到「比對」頁籤選兩個日期按「開始比對」，就能看到新進榜、掉出榜、評級升降與股價變化。
  9. 備份：按「匯出 JSON / CSV」可存檔。更換瀏覽器或清除資料後，在「比對」頁籤用「匯入先前匯出的 JSON」把舊結果加回來。

注意：分數是依你貼上的投資心法機械式計算，僅作篩選參考，不是投資建議。會計師意見等地雷無法由 FinMind 取得，需自行查證。
