#### 第二維：估值與安全邊際（價格評估）
*   **本益比（P/E）區間劃分**：
    *   以歷史本益比河流圖觀察，當台積電本益比落於 **15 倍或以下** 時，屬於極具安全邊際的「便宜價/合理下限」。
    *   當 P/E 達到 25 倍以上時，反映市場給予的高成長預期，此時追高風險增加；長線若本益比飆升至 40 倍以上則達到昂貴賣出目標。
*   **現金股利折現與 ROE 估值**：
    *   台積電長年 ROE 保持在 20%~25% 以上的高水準，配合穩健且持續成長的現金股利政策，具備複利增長的內在價值。

#### 第三維：籌碼面與法人動向（主力資金鎖碼）
*   **三大法人與 MSCI 權重**：

*   **恐慌超跌買點（融資維持率）**：
